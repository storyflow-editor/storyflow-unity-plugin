##### New Features

- **Dialogue Rollback**: Enable Dialogue Rollback in StoryFlow Editor's project settings, export again and the plugin keeps a bounded history of earlier dialogue steps. `GoBack()` on the dialogue component returns to the previous interaction and restores story globals and locals, script and loop positions, once-only choices, character values, Data Asset runtime writes and the story's random stream. The supplied dialogue UI base has an optional **Back Button** field, and `SetBackAllowed(bool)` adds your own enabled condition. Rollback is off by default and costs nothing while it is off

- **Block Rollback**: Call Block Rollback, or place the Block Rollback node in a story graph, before work that cannot be undone, such as granting an achievement or writing to a server. It clears the retained history, so Back cannot cross that point

- **Localized Data Asset Overrides**: A string a child Data Asset overrides is now translated like the declared value it replaces. Fields that opt out of localization in StoryFlow Editor stay as authored

- **Configurable Script Nesting Limit**: The maximum depth of Run Script calls follows the project's setting in StoryFlow Editor, so the plugin stops a runaway chain at the same depth the editor does

##### Improvements

- **Error Reporting Matches StoryFlow Editor**: A missing script, a missing flow, a Run Flow with no Entry Flow and a Start node with nothing connected now raise the same errors the editor shows

##### Bug Fixes

- **For Each Loops Stopped After Their First Element**: A loop whose body ended on an unconnected Random Branch, Switch On Enum or Branch output, a Block Rollback node, an empty flow, an empty Loop Body or a Run Script with nothing connected after it stalled on the first element and never reached Completed. The loop now moves on to its next element, whichever node the body ends on

- **Long Loops Were Cut Off**: A node-count guard stopped loops over a few hundred elements. The guard now counts nodes since the last loop step, so long array and map loops run to the end

- **For Each Followed Its Array While Looping**: Adding to an array inside its own For Each body kept extending the loop. A loop now iterates the elements it had when it started

- **Set Array With Nothing Wired Emptied the Variable**: A Set Array node whose array input is not connected now leaves the variable as it is

- **A Dead End Left the Line Refusing Input**: Choosing an option that leads nowhere left the dialogue unable to accept another choice. The current line stays usable

- **Exit Flows With No Route Returned to the Caller**: A called script that ends on an exit route nobody connected now stays in the script instead of returning through the default output

- **End Inside Nested Flows Stalled**: An End reached inside nested flows of the starting script now ends the story

- **Variables Sharing a Name Across Scopes**: A local and a global variable with the same name could be confused. The node's own scope now decides which one it reads and writes, and change events report the right scope

- **Unwired Run Script Array Parameters**: An array parameter left unconnected now passes an empty array, as it does in StoryFlow Editor, instead of the called script's default
